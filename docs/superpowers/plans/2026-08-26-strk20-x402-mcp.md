# STRK20 x402 MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Make the local MCP settle canonical x402 v2 paywalls with STRK20 on Sepolia, guide setup at /setup, and verify the complete flow deterministically and live.

**Architecture:** Keep the existing local MCP, merchant, Keychain wallet, Tor fetcher, and STRK20 action builder. Migrate their HTTP contract together to strict x402 v2, add one explicit shield lifecycle operation, then prove the joined path through the real MCP transport. Use no facilitator because the merchant verifies the Starknet receipt directly.

**Tech Stack:** Node.js 24, TypeScript type stripping, Express 5, MCP SDK 1.30, Starknet.js 10.7, STRK20 privacy SDK/client, Next.js 16 App Router, React 19, node:test.

**Spec:** docs/superpowers/specs/2026-08-26-strk20-x402-mcp-design.md

## Global Constraints

- Live target: Starknet Sepolia with test STRK. Do not claim the headless paywall works on mainnet.
- Strict x402 v2 headers only: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE.
- Scheme strk20-anonymizer, network starknet:SN_SEPOLIA, flow upfront.
- Keep MCP loopback-only and Tor-only. Never expose arbitrary HTTP headers to MCP callers.
- Never expose keys, passphrases, viewing material, AVNU keys, or private balances.
- Preserve helper allowlisting, both price ceilings, resource binding, and numeric felt comparison.
- Add no facilitator, database, UI framework, or application dependency.
- Read local Next.js 16 docs before web changes.
- Use red-green TDD and a scoped commit for each task.
